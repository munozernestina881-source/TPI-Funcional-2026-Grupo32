## Descripción del Proyecto
[cite_start]Este proyecto implementa el núcleo lógico de un sistema embebido para el control de semáforos en intersecciones urbanas críticas, desarrollado íntegramente bajo el paradigma de programación funcional[cite: 202, 209]. 

[cite_start]El sistema gestiona las transiciones de colores, la temporización mediante tiempo Unix, auditorías forenses del tráfico y el análisis de la duración de los ciclos semafóricos[cite: 213, 222, 235, 246]. [cite_start]Todo el código en Lisp fue construido respetando el principio de inmutabilidad absoluta y la ausencia total de bucles imperativos, utilizando en su lugar recursividad de cola y funciones de orden superior[cite: 13, 15, 16]. [cite_start]Adicionalmente, el proyecto incluye una reimplementación y estudio comparativo de estas funciones en un segundo lenguaje asignado[cite: 48, 50].
