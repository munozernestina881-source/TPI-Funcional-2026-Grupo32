## Descripción del Proyecto
Este proyecto implementa el núcleo lógico de un sistema de control para semáforos en intersecciones urbanas críticas, desarrollado íntegramente bajo el paradigma de programación funcional. 

El sistema gestiona las transiciones de colores, la temporización mediante tiempo Unix, auditorías forenses del tráfico y el análisis de la duración de los ciclos semafóricos. Todo el código en Lisp fue construido respetando el principio de inmutabilidad absoluta y la ausencia total de bucles imperativos, utilizando en su lugar recursividad de cola y funciones de orden superior. Adicionalmente, el proyecto incluye una reimplementación y estudio comparativo de estas funciones en un segundo lenguaje asignado.

## Estructura del Repositorio
La organización de los archivos responde estrictamente a la arquitectura solicitada para la evaluación:

* **`/lisp/core.lisp`**: Código base en Common Lisp que resuelve los requerimientos de lógica urbana y temporización.
* **`/comparativa/solucion.[extensión]`**: Código con la reimplementación de las funciones de transición y temporizador en el lenguaje funcional asignado para la Fase 3.
* **`/docs/INFORME.pdf`**: Documento técnico analítico que incluye los fundamentos de diseño, justificación de librerías, bitácora de depuración y respuestas teóricas.
* **`/docs/HONOR.md`**: Declaración individual obligatoria de autoría y Código de Honor.
